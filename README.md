# Fabbery

Static GitHub Pages site for Fabbery 3D-printable designs.

## Publish on GitHub

1. Upload the contents of this archive to the root of `fabbery/fabbery.github.io`.
2. Keep the `main` branch selected in the repository settings.
3. In **Settings → Pages**, publish from the `main` branch and the repository root.
4. Open `https://fabbery.github.io/` after GitHub Pages finishes deploying.

The repository includes a `CNAME` file for `fabbery.world`. After DNS propagation, the site will be available at `https://fabbery.world/`.

## Manage the site

Open `https://fabbery.github.io/admin/` and sign in with a GitHub personal access token that can read and write repository contents.

- **Model gallery** lets you create, rename and reorder collections, then manage model photos, names, descriptions and dates inside them
- **Site links** manages Patreon, Pinterest and Instagram URLs

The three models with the newest `Added on` dates appear in **Latest designs**. Uploaded images are stored in `photos/`.
